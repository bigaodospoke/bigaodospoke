## 🚀 Sobre o Trainerly

Trainerly é uma plataforma competitiva para Pokémon desenvolvida para reunir diversas ferramentas em um único lugar.

### Funcionalidades

- Team Builder
- Pokédex Competitiva
- Damage Calculator
- Integração com Pokémon Showdown
- Login com Discord
- Análise de Times
- Rankings e Estatísticas
